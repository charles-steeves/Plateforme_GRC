# COURSE_MAPPING — v3.0
Source : support fourni « La Gestion de la Relation Client (GRC) », Mme ASSENGONE épouse EHOUMBE Preslya Carelle Nancy. Le projet traduit les notions, il ne prétend pas implémenter exhaustivement tout le cours.
| Notion du cours | Fonctionnalité à démontrer | Priorité |
|---|---|---|
| Connaissance client/base de données | Fiches, historique commandes, préférences minimales | P0 |
| GRC analytique | Dashboard, segmentation clients nouveaux/occasionnels/réguliers/inactifs, satisfaction | P0 |
| GRC opérationnelle | Suivi commandes, statuts, produits/stock, contacts via SAV | P0 |
| GRC interactive | Espace client, tickets et dialogue avec administration | P0 |
| Fidélisation | Attribution et historique des points après livraison | P0 |
| SAV | Ouverture, traitement, messages, clôture d'un ticket | P0 |
| Cycle de vie client | Étiquettes calculées selon achats/inactivité ; inactif ≠ perdu | P0 |
| Personnalisation et marketing | Offre ciblée simulée, préférences, prospection | P1 |
| E-CRM | Interactions et notifications visibles dans l'application, sans envoi réel | P0/P1 |
| CLV / churn réel | Non calculés sans données adaptées ; seulement explication pédagogique | Hors P0 |
Les indicateurs portent tous la mention « Données de démonstration ». Aucun chiffre général du cours n'est présenté comme un résultat mesuré de la boutique.
